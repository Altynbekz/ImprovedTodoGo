# ImprovedTodoGo

A RESTful Todo API built with Go, PostgreSQL, `sqlc`, and JWT authentication.

## Tech Stack

- **Language:** Go (`net/http`)
- **Database:** PostgreSQL with type-safe queries generated by [`sqlc`](https://sqlc.dev/)
- **Migrations:** SQL schemas for [`goose`](https://github.com/pressly/goose)
- **Authentication:** Argon2id password hashing (`alexedwards/argon2id`) + HS256 JWT (`golang-jwt/jwt/v5`)

## Project Structure

```text
.
├── cmd/api/              # Server entrypoint (listens on :8082)
├── internal/
│   ├── api/              # ApiConfig (DB queries + JWT secret)
│   ├── auth/             # Password hashing, JWT creation/validation, Bearer parsing
│   ├── database/         # sqlc-generated PostgreSQL queries and models
│   ├── todos/            # HTTP handlers, request/response models, and unit tests
│   ├── utils/            # JSON response helpers
│   └── routes.go         # Router setup and CORS middleware
├── sql/
│   ├── schema/           # Database migrations (users, tasks)
│   └── queries/          # SQL queries for sqlc
└── sqlc.yaml             # sqlc configuration
```

## API Endpoints

### Users & Auth
| Method | Path | Auth | Description |
| :--- | :--- | :--- | :--- |
| `POST` | `/api/user` | Public | Register a new user |
| `POST` | `/api/login` | Public | Authenticate and receive a JWT |
| `PUT` | `/api/user` | Bearer JWT | Update user profile (`?username=...`) |
| `DELETE` | `/api/user` | Bearer JWT | Delete user account (`?username=...`) |

### Todos
| Method | Path | Auth | Description |
| :--- | :--- | :--- | :--- |
| `POST` | `/api/todo` | Bearer JWT | Create a new task |
| `GET` | `/api/todo` | Bearer JWT | List all tasks for the user (`?username=...`) |

## Development

### Run tests
```bash
go vet ./...
go test -v ./...
```

### Regenerate database code
After editing files in `sql/queries/` or `sql/schema/`:
```bash
sqlc generate
```

### Run the server
```bash
go run ./cmd/api
```
